# Sales_Analysis-Excel
Sales analysis project using Microsoft Excel with monthly, weekly and quarterly reports.

📌 Project Overview

This project focuses on analyzing sales data using Microsoft Excel. The analysis provides insights into sales performance across different time periods using monthly, weekly, and quarterly reports.

🎯 Objectives
- Analyze overall sales performance
- Identify monthly sales trends
- Analyze weekly sales performance
- Compare quarterly sales results
- Present business insights using Excel reports
- Support data-driven decision making

📂 Dataset
The dataset contains sales records used for performing the analysis.

The project includes:

- Sales transaction data
- Monthly sales analysis
- Weekly sales analysis
- Quarterly sales analysis

🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Excel Formulas
- Data Visualization
- Reporting

📈 Analysis Performed

Monthly Sales Analysis
Analyzed sales performance month by month to identify trends and changes in sales.

Weekly Sales Analysis
Analyzed weekly sales data to understand short-term sales performance.

Quarterly Sales Analysis
Compared quarterly sales performance to identify strong and weak business periods.

- Sales Analysis
